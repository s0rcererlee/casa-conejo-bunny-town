# Casa Conejo · 兔兔小镇

基于 Three.js 的 3D 自主生活小镇。包含兔兔一家三口、四季昼夜、彩色民居、游乐设施、龙达竹林与熊猫、火烈鸟、骑车与日常互动。

## 本地运行

安装 Node.js 与 Python 3，然后执行：

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:8766/ 。音乐需要在页面内点击开启。

也可直接用静态 HTTP 服务器托管 `out/`，无需构建或后端。请勿通过 file:// 打开。

## 文件

- 根目录 JavaScript：可编辑场景、角色、行为及界面源码。
- `town.glb` / `world.json`：当前场景模型及空间数据。
- `audio/`：音频资源与来源说明。
- `blender/`：历史建模与场景扩建脚本，仅作生成过程参考；不是当前网页构建步骤，可能含原开发机路径。
- `prepare-public.mjs`：从 world.js 收集依赖生成静态发布目录。
- `out/`：已生成的可部署版本，包括 Three.js vendor 依赖。

性能优化包括静态建筑合并、竹林实例化、30/60帧切换、后台暂停和按可见范围筛选灯光。
